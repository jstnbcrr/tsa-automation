About This Project

Tech Stack Automation LLC is a senior capstone project for ISA 4600 at Utah Tech University. The project demonstrates how small and medium-sized businesses can leverage no-code automation tools to replace expensive enterprise software stacks.

Every workflow on this site is production-grade — built on n8n Cloud, connected to real Google accounts, powered by OpenAI GPT-4o, and capable of processing live submissions.
