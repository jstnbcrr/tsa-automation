Project Overview

Built for real.
Runs in production.

Tech Stack Automation LLC is not a mock project. Every workflow handles live data, fires real emails, logs to real spreadsheets, and calls real AI APIs.

The core thesis: SMBs don't need Salesforce, Zendesk, or Expensify. They need smart, lightweight automations connecting the tools they already use — and n8n makes that possible for $25/month.

"Replace $1,000+/month enterprise software stacks with purpose-built n8n workflows — without sacrificing capability, reliability, or professionalism."

Reflection

What I built.
What I learned.

This project started as a question: can a small business run enterprise-level automation without an IT department or a $50K software budget? The answer is yes — and this site is the proof.

Building 13 production workflows forced me to think like a systems designer, not just a student. Every workflow had to handle real errors, real edge cases, and real data. The Google OAuth2 delays, the n8n expression syntax, the GPT-4o prompt engineering — none of it was theoretical.

The most important thing I learned: automation is not about replacing people. It's about removing the friction that stops people from doing their best work.

Key Takeaways
1

No-code ≠ No skill

n8n required deep understanding of APIs, JSON, Luxon date math, conditional logic, and error handling — just without writing full application code.

2

GPT-4o needs structure

Getting consistent, parseable output from an LLM requires careful prompt engineering, structured JSON schemas, and robust parsing logic.

3

OAuth2 is a real constraint

Google's account verification requirements created real project delays — a lesson in planning for external dependencies and platform policies.

4

Ship fast, fix in prod

Testing 13 workflows perfectly before deployment isn't realistic. Building good error handling and alerts matters more than perfect pre-launch testing.

5

Design is part of the deliverable

A well-designed portfolio site communicates technical credibility before anyone reads a single line of documentation.
